## Лабораторна робота № 1 (Варіант 4)

Параметри: номер за списком N = 4, коефіцієнт підгрупи k = 0.5.

Цільова функція: W = 2.0 x1 + 2.4 x2 -> max  
Обмеження за сировиною: 1.0 x1 + 4.0 x2 <= 1700  
Обмеження за машинним часом: 8.0 x1 + 0.8 x2 <= 1600  
Граничні умови: x1 >= 0, x2 >= 0  

Оптимальний неперервний план: x1* = 161.54 шт., x2* = 384.62 шт., прибуток W_max = 1246.15 грн. Залишки ресурсів: сировина - 0 од. (100%), машинний час - 0 год. (100%).  
Практичний цілочисельний план: x1 = 160 шт., x2 = 385 шт., прибуток W = 1244.00 грн. Залишки: сировина - 0 од., машинний час - 12.0 год. (використання 99.25%).
