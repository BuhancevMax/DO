## 🌟 Лабораторна робота № 1 (Варіант 4)

> 👉 **[ВІДКРИТИ ПОВНИЙ ОФІЦІЙНИЙ ЗВІТ З ТИТУЛЬНИМ АРКУШЕМ](reports/lab1/README.md)**

### Коротке резюме результатів:
- **Цільова функція:** $W(x_1, x_2) = 4 x_1 + 4.8 x_2 \to \max$
- **Обмеження на ресурси:**
  - $2 x_1 + 4 x_2 \le 1700$ (сировина)
  - $4 x_1 + 1.6 x_2 \le 1600$ (машинний час)
  - $x_1 \ge 0, \quad x_2 \ge 0$

## 🖥️ Інтерактивний веб-інтерфейс (SPA)

У репозиторії створено повнофункціональний інтерактивний інтерфейс у файлі [`index.html`](index.html), який підтримує:
1. Зміну параметрів студента ($N$, коефіцієнт $k$, ліміти запасів).
2. Динамічну перемальовку області допустимих розв'язків на HTML5 Canvas у реальному часі.
3. Інтерактивний повзунок лінії рівня цільової функції.
4. Миттєвий перерахунок прибутку та залишків ресурсів.
5. Перемикання між лабораторними роботами та вбудований перегляд звіту.

> Для запуску відкрийте `index.html` у будь-якому сучасному веббраузері або увімкніть **GitHub Pages** у налаштуваннях репозиторію.

## 📂 Структура репозиторію

```text
DO/
├── README.md                      # Головна сторінка-дашборд з навігацією (цей файл)
├── index.html                     # Інтерактивний веб-інтерфейс (GitHub Pages)
├── .gitignore                     # Правила ігнорування тимчасових файлів
│
├── labs/                          # Програмні коди та робочі матеріали
│   ├── lab1/
│   │   ├── README.md              # Швидкий огляд ЛР 1 та інструкція

│   │   └── solver.py              # Python-скрипт розв'язку та побудови графіків
```
