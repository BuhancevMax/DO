## Лабораторна робота № 1 (Варіант 4)

- **Цільова функція:** $W = 4.0 x_1 + 4.8 x_2 \to \max$
- **Обмеження:**
  - $2.0 x_1 + 4.0 x_2 \le 1700$ (сировина)
  - $4.0 x_1 + 1.6 x_2 \le 1600$ (машинний час)
  - $x_1 \ge 0, \quad x_2 \ge 0$
- **Оптимальний неперервний план:** $x_1^* = 287.50$ шт., $x_2^* = 281.25$ шт., прибуток $W_{\max} = \mathbf{2500.00}$ грн.  
  Залишки ресурсів: сировина — $0$ од. ($100\%$), машинний час — $0$ год. ($100\%$).
- **Практичний цілочисельний план:** $x_1 = 286$ шт., $x_2 = 282$ шт., прибуток $W = \mathbf{2497.60}$ грн.
